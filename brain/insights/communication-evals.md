# Communication evals

**Observation:** the simulation will produce communication artifacts (status updates, incident comms, RCAs, decision defenses, review comments). These could be scored against a rubric, the same way agent evals score model outputs.

**Why it matters:** communication weighs heavily in mid-level (Pleno) interviews and day-to-day work, and the learning path has no objective evidence for the `Communication` competency yet.

**Evidence:** operator request (2026-10-08). No rubric or baseline exists.

**Possible impact:** a rubric per artifact type (for example: clarity, impact stated, evidence, risk, next step, role-appropriate voice), scored per session, would give evidence to move `Communication` in `docs/learning/LEARNING-PATH.md` and to justify a training-level change. Natural fit after Bootstrap 02 creates meetings and tickets, or in Stage 7 with agent evals.

**Needs validation?** Yes: whether rubric scoring by an AI is consistent enough to be useful (same answer, same score). Not scheduled; decide in a later bootstrap.
